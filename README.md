# SQL-Portfolio-
SQL Queries solutions 
This project focused on analyzing a retail sales dataset to uncover key business insights using SQL. The objective was to support decision-making by exploring sales trends, customer behavior, and product performance.

Tools:
SQL (PostgreSQL/MySQL), Excel/Tableau (optional for visualization)

Key Tasks:

Cleaned and preprocessed raw sales data by handling null values, duplicates, and formatting issues.

Wrote advanced SQL queries using JOINs, CTEs, and window functions to generate meaningful reports.

Identified top-performing products, peak sales months, and regional sales trends.

Performed customer segmentation based on purchase frequency and average spend.

Calculated KPIs like total revenue, average order value, and customer retention metrics.

Created summary tables for business dashboards.

Impact:
The analysis provided actionable insights into product performance and customer behavior, aiding better inventory and marketing strategies. This project showcases my ability to use SQL for real-world business analytics.
